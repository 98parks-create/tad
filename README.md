# TAD스마트견적

**광고물 제조업체를 위한 AI 견적 자동화 SaaS**

광고물 제조 현장에서는 고객 견적 요청이 전화·문자로 들어오고, 사장님이 일일이 수기로 견적서를 만듭니다.
이 반복 작업을 줄이기 위해, 견적 요청을 입력하면 AI가 견적서를 자동 생성해주는 서비스를 만들었습니다.

- **서비스**: https://tadsmart.co.kr (도메인 구입, 실배포, 운영)
- **개발 기간**: 개인 프로젝트 (기획 → 개발 → 배포 → 운영 전 과정 단독 수행)

## 주요 기능

- 견적 요청 정보 입력 → AI 기반 견적서 자동 생성
- 견적 이력 관리 및 조회
- 구독 결제 모델 (월 9,900원)

## 기술 스택

- **Frontend**: React 19
- **Backend / DB**: Firebase
- **AI**: Claude API

## 문제 해결 경험

### AI 출력 오류율 80% 이상 개선

**문제**: 초기에 AI가 엉뚱한 금액이나 형식이 깨진 견적을 출력하는 비율이 10건 중 4~5건에 달해, 실사용이 불가능한 수준이었습니다.

**과정**:
1. 오류가 날 때마다 코드를 수정하는 방식으로는 한 곳을 고치면 다른 곳이 깨지는 문제가 반복
2. 접근을 바꿔, 오류 발생 시 입력값과 출력값을 기록하며 오류 유형을 분류
3. 분석 결과, 입력 형식이 일정하지 않을 때와 프롬프트 지시가 모호할 때 오류가 집중된다는 패턴 발견

**해결**:
- 출력 형식을 명확히 지정하고 예외 처리를 명시하도록 프롬프트 재설계
- 형식에 맞지 않는 출력을 걸러내는 검증(fallback) 로직 추가

**결과**: 오류율 80% 이상 감소, 실사용 가능한 서비스로 안정화

## 배운 점

- 문제를 감으로 고치지 않고, 기록으로 원인을 좁혀가는 디버깅 방식
- AI 응답은 신뢰할 수 없다는 전제로 검증 계층을 설계해야 한다는 것
- 기획부터 운영까지 서비스 전체 생명주기를 혼자 책임져본 경험
